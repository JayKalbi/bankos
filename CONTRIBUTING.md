# Contributing to BankOS

We welcome contributions! To ensure this platform remains at Tier-1 enterprise quality, all contributions must adhere to our strict governance policies.

## Development Workflow
1. Fork the repository.
2. Create your feature branch (git checkout -b feature/AmazingFeature).
3. If changing architecture, you MUST submit an Architecture Decision Record (ADR) in docs/adr/.
4. Commit your changes (git commit -m 'Add some AmazingFeature').
5. Push to the branch (git push origin feature/AmazingFeature).
6. Open a Pull Request against develop.

## Architecture Decisions
All structural, technology, or pattern decisions must be logged as an ADR using the standard Markdown format before code is merged.
